[1] Optimizing LLMs Using Quantization for Mobile Execution
Source: arXiv
URL: http://arxiv.org/abs/2512.06490v1
Published: 2025-12-06T16:31:56+00:00

Content Preview:
Large Language Models (LLMs) offer powerful capabilities, but their significant size and computational requirements hinder deployment on resource-constrained mobile devices. This paper investigates Post-Training Quantization (PTQ) for compressing LLMs for mobile execution. We apply 4-bit PTQ using the BitsAndBytes library with the Hugging Face Transformers framework to Meta's Llama 3.2 3B model. The quantized model is converted to GGUF format using llama.cpp tools for optimized mobile inference.
